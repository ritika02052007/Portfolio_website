Ritika Saini Portfolio (HTML, CSS, JavaScript only)

Open index.html in any browser. No installation needed.

Files:
- index.html: page structure
- css/style.css: design, colors, fonts, 3D styles
- js/script.js: 3D globe, star background, tilt cards, filters, theme toggle

To edit content (skills, projects, certificates), change the data arrays at the top of js/script.js.
Default theme is dark; change colors in the :root block of css/style.css.
